# **App Name**: OIA Governance System

## Core Features:

- Dependency Installation: Install framer-motion, lucide-react, recharts, clsx, and tailwind-merge for enhanced UI capabilities.
- Tailwind Configuration: Configure Tailwind CSS with custom fonts (Cairo), colors (royal-900, royal-800, gold-500, gold-400, danger, success), and effects (glass).
- Global CSS Reset: Implement global CSS styles including a radial gradient background, Cairo font, and white text color.

## Style Guidelines:

- Deep Navy Background: Use #001220 for the deepest navy background to create a sophisticated feel.
- Card Background: Use #001A33 for card backgrounds to provide a subtle contrast.
- Primary Accent (Champagne Gold): Use #D4AF37 for the primary accent to convey luxury and elegance.
- Hover State: Use #E5C565 for hover states to indicate interactivity.
- Risk Alerts: Use #FF3B3B for risk alerts to draw immediate attention.
- High Maturity: Use #00E096 for indicating high maturity, representing success and stability.
- Font: 'Cairo' (sans-serif) for a modern, readable typeface.
- Glass Effect: Apply 'backdrop-filter: blur(12px); background: rgba(255, 255, 255, 0.03); border: 1px solid rgba(255, 255, 255, 0.05);' for a frosted glass effect.
